# Python 数据类型与函数速查

函数直接调用：`len(a)`；方法跟在对象后：`a.append(1)`；`in`、切片、`del` 是语法，不是函数。

表中含变量的示例，每行独立执行，初始值见所在小节。`None` 是一个值，不是字符串 `"None"`。

## 1. 数据类型总览

| 类型 | 示例 | 特点 |
|---|---|---|
| `int` 整数 | `10`、`-3`、`0xFF` | 不可变；支持算术、位运算 |
| `float` 浮点数 | `3.14`、`1e3` | 不可变；小数计算可能有精度误差 |
| `bool` 布尔值 | `True`、`False` | 不可变；表示真、假 |
| `NoneType` 空值类型 | `None` | 表示没有值；判断用 `is None` |
| `str` 字符串 | `"abc"` | 有序、不可变；没有单独的字符类型，`"a"` 也是字符串 |
| `list` 列表 | `[1, 2, 1]` | 有序、可重复、可变 |
| `tuple` 元组 | `(1, 2)`、`(1,)` | 有序、可重复；元素位置不可修改 |
| `dict` 字典 | `{"A": 1}` | 键唯一、可变；Python 3.7 起保证保留插入顺序 |
| `set` 集合 | `{1, 2}`、`set()` | 元素唯一、无序、可变；没有下标 |
| `range` 整数序列 | `range(5)` | 不可变；按规则表示整数序列，不预先存储全部整数 |
| `bytes` 字节串 | `b"abc"` | 有序、不可变；每个元素是 `0~255` 的整数 |
| `bytearray` 字节数组 | `bytearray(b"abc")` | `bytes` 的可变版本 |
| `frozenset` 冻结集合 | `frozenset({1, 2})` | 不可变的集合；可作字典键、集合元素 |
| `complex` 复数 | `1 + 2j` | 不可变；算法题较少用 |

## 2. 类型判断与转换

| 写法 | 结果 | 注意 |
|---|---|---|
| `type(3)` | `<class 'int'>` | 查看具体类型 |
| `isinstance(3, int)` | `True` | 判断是否属于某类型，也包含其子类 |
| `isinstance(3, (int, float))` | `True` | 满足任意一个类型即可 |
| `int("12")` | `12` | 默认按十进制转换 |
| `int("1010", 2)` | `10` | 第二个参数指定进制 |
| `int("FF", 16)` | `255` | 十六进制字符串转整数 |
| `int(-3.9)` | `-3` | 向零截断，不是向下取整 |
| `float("3.14")` | `3.14` | `float("abc")` 报 `ValueError` |
| `str(123)` | `'123'` | 转成字符串 |
| `bool(0)` | `False` | 真值规则见下一节 |
| `list("abc")` | `['a', 'b', 'c']` | 将可迭代对象转成列表 |
| `tuple([1, 2])` | `(1, 2)` | 转成元组 |
| `set([2, 1, 2])` | `{1, 2}` | 去重；显示、遍历顺序不保证 |
| `dict([("A", 1), ("B", 2)])` | `{'A': 1, 'B': 2}` | 每项必须是一对键和值；重复键以后者为准 |

`int("3.5")` 会报错，不能直接把带小数点的字符串转成整数。`bool("False")` 是 `True`，因为它是非空字符串。

## 3. 数值、布尔值与空值

### 算术与取整

| 写法 | 结果 | 作用 |
|---|---|---|
| `7 + 2`、`7 - 2`、`7 * 2` | `9`、`5`、`14` | 加、减、乘 |
| `7 / 2` | `3.5` | 普通除法；整数相除也得到浮点数 |
| `7 // 2` | `3` | 向下取整除法；`-7 // 2` 是 `-4` |
| `7 % 2` | `1` | 取余；`-7 % 2` 是 `1` |
| `divmod(7, 2)` | `(3, 1)` | 同时返回整除结果和余数 |
| `2 ** 3`、`pow(2, 3)` | `8`、`8` | 乘方 |
| `pow(2, 10, 100)` | `24` | 计算幂后取模；无需生成完整的大整数幂 |
| `abs(-3)` | `3` | 绝对值 |
| `round(3.14159, 2)` | `3.14` | 保留到小数点后两位；不保证显示尾部的零 |
| `round(2.5)`、`round(3.5)` | `2`、`4` | 恰好居中时取偶数，不是通常说的逢五进一 |

浮点数不能精确表示所有十进制小数：`0.1 + 0.2 == 0.3` 是 `False`。近似比较用 `math.isclose()`，见工具模块。

### 进制与位运算

| 写法 | 结果 | 作用 |
|---|---|---|
| `bin(10)`、`oct(10)`、`hex(10)` | `'0b1010'`、`'0o12'`、`'0xa'` | 转成带进制前缀的字符串 |
| `format(10, "08b")` | `'00001010'` | 二进制，至少 8 位，左补零，无前缀 |
| `format(10, "08X")` | `'0000000A'` | 十六进制大写，至少 8 位，无前缀 |
| `5 & 3` | `1` | 按位与：两位都是 1 才得 1 |
| `5 \| 3` | `7` | 按位或：至少一位是 1 就得 1 |
| `5 ^ 3` | `6` | 按位异或：两位不同得 1 |
| `~5` | `-6` | 按位取反；整数中 `~x == -x - 1`，不是只翻转显示出的几位 |
| `5 << 1`、`5 >> 1` | `10`、`2` | 左移、右移；整数右移相当于整除对应的 2 的幂 |
| `(10).bit_length()` | `4` | 表示绝对值所需的二进制位数；0 得到 0 |
| `(10).bit_count()` | `2` | 绝对值的二进制中有几个 1；Python 3.10+ |
| `ord("A")`、`chr(65)` | `65`、`'A'` | 单个字符与 Unicode 编号互转 |

### 真值与判断

| 写法 / 值 | 含义 / 结果 |
|---|---|
| `False`、`None`、`0`、`0.0`、`""`、`[]`、`()`、`{}`、`set()`、`range(0)` | 在条件判断中为假 |
| 非零数、非空容器 | 在条件判断中为真 |
| `not x` | 对 x 的真值取反，结果是布尔值 |
| `a and b` | a 为假时返回 a，否则返回 b |
| `a or b` | a 为真时返回 a，否则返回 b |
| `x == y`、`x != y` | 比较值是否相等、不相等 |
| `x is None`、`x is not None` | 判断是否为空值；不要用 `is` 比较普通数字、字符串的值 |
| `0 <= x < 10` | 连续比较；等价于 `0 <= x and x < 10` |

`and`、`or` 会短路，不一定返回布尔值：`0 or 5` 得到 `5`，`[] and 5` 得到 `[]`。判断条件优先用 `and`、`or`，不要与按位运算 `&`、`|` 混淆。

`bool` 是 `int` 的子类：`True == 1`，`False == 0`，`isinstance(True, int)` 是 `True`；它们作为字典键、集合元素时也会被视为相等。

## 4. str：字符串

字符串不可变。下面的转换方法返回新字符串；查询方法可能返回整数、布尔值、列表等。

### 分割、拼接与替换

| 写法 | 结果 | 注意 |
|---|---|---|
| `"a,b,c".split(",")` | `['a', 'b', 'c']` | 按指定分隔符分割 |
| `" a  b\tc ".split()` | `['a', 'b', 'c']` | 不传参数：按连续空白分割，去掉首尾空白，不产生空字符串项 |
| `"a,,b,".split(",")` | `['a', '', 'b', '']` | 指定分隔符时会保留空项 |
| `"a,b,c".split(",", 1)` | `['a', 'b,c']` | 最多切 1 次 |
| `"a,b,c".rsplit(",", 1)` | `['a,b', 'c']` | 从右侧最多切 1 次 |
| `"a\nb\n".splitlines()` | `['a', 'b']` | 按行分割，默认不保留换行符 |
| `",".join(["a", "b"])` | `'a,b'` | 分隔符写在前面；所有元素都必须是字符串 |
| `"".join(map(str, [1, 2]))` | `'12'` | 数字先转字符串再拼接 |
| `"a=b=c".partition("=")` | `('a', '=', 'b=c')` | 只切第一个分隔符，固定返回三元组 |
| `"abc".partition("=")` | `('abc', '', '')` | 分隔符不存在也返回三元组 |
| `"banana".replace("a", "A", 2)` | `'bAnAna'` | 最多替换 2 次；省略次数则全部替换 |

`split("")` 会报 `ValueError`；按字符拆分用 `list(s)`。

### 查找与统计

| 写法 | 结果 | 注意 |
|---|---|---|
| `"banana".find("na")` | `2` | 第一次出现的下标；找不到返回 `-1` |
| `"banana".rfind("na")` | `4` | 最后一次出现的下标；找不到返回 `-1` |
| `"banana".index("na")` | `2` | 找不到报 `ValueError` |
| `"banana".find("na", 3)` | `4` | 从下标 3 开始查找；还可传结束下标，结束位置不包含 |
| `"aaaa".count("aa")` | `2` | 统计不重叠的出现次数 |
| `"ana" in "banana"` | `True` | 判断是否包含子串 |
| `"abc".startswith("ab")` | `True` | 判断前缀 |
| `"a.txt".endswith((".txt", ".md"))` | `True` | 多个候选写成元组，任意一个匹配即可 |

### 清理、大小写与补齐

| 写法 | 结果 | 注意 |
|---|---|---|
| `"  abc\n".strip()` | `'abc'` | 去掉两端空白，不处理内部 |
| `"xxabcxy".strip("xy")` | `'abc'` | 参数是可删除的字符集合，不是完整前后缀 |
| `"  a  ".lstrip()`、`"  a  ".rstrip()` | `'a  '`、`'  a'` | 只去左侧、右侧空白 |
| `"abc".upper()`、`"AbC".lower()` | `'ABC'`、`'abc'` | 转大写、转小写 |
| `"hello world".capitalize()` | `'Hello world'` | 首字符大写，其余小写 |
| `"hello world".title()` | `'Hello World'` | 单词首字母大写 |
| `"AbC".swapcase()` | `'aBc'` | 大小写互换 |
| `"12".zfill(5)` | `'00012'` | 左侧补零到至少 5 位；负号保留在最前面 |
| `"a".ljust(3, "_")`、`"a".rjust(3, "_")` | `'a__'`、`'__a'` | 左对齐、右对齐；填充字符必须只有 1 个 |
| `"a".center(3, "_")` | `'_a_'` | 居中补齐 |
| `"pre_abc".removeprefix("pre_")` | `'abc'` | 去掉完整前缀；Python 3.9+ |
| `"a.txt".removesuffix(".txt")` | `'a'` | 去掉完整后缀；Python 3.9+ |

### 内容判断与格式化

| 写法 | 结果 | 注意 |
|---|---|---|
| `"123".isdecimal()` | `True` | 是否全是十进制数字字符；也包含部分非 ASCII 数字 |
| `"²".isdigit()` | `True` | 比 `isdecimal()` 范围更宽，不能据此保证 `int(s)` 成功 |
| `"四".isnumeric()` | `True` | 数字范围更宽，包含部分汉字数字 |
| `"中文Ab".isalpha()` | `True` | 是否全是字母，包含汉字等 Unicode 字符 |
| `"abc123".isalnum()` | `True` | 是否全是字母或数字 |
| `" \t\n".isspace()` | `True` | 是否全是空白字符 |
| `"ABC1".isupper()`、`"abc1".islower()` | `True`、`True` | 只检查有大小写的字符，且至少要有一个这类字符 |
| `"abc".isascii()` | `True` | 是否全是 ASCII 字符；空字符串也返回 `True` |
| `f"{3.1:.2f}"` | `'3.10'` | 固定显示两位小数 |
| `f"{10:08X}"` | `'0000000A'` | 格式规则与 `format(10, "08X")` 相同 |
| `"{}-{}".format("A", 1)` | `'A-1'` | 按占位符填值 |

`isdecimal()`、`isdigit()`、`isnumeric()`、`isalpha()`、`isalnum()`、`isspace()` 对空字符串都返回 `False`。正负号、小数点也不属于数字字符。

## 5. 序列通用操作：str / list / tuple / range

示例：`a = [10, 20, 30, 40, 50]`。下标从 0 开始。

| 写法 | 结果 | 规则 |
|---|---|---|
| `a[0]`、`a[-1]` | `10`、`50` | 第一个、最后一个；下标越界报 `IndexError` |
| `a[1:4]` | `[20, 30, 40]` | 包含起点，不包含终点 |
| `a[:2]`、`a[2:]` | `[10, 20]`、`[30, 40, 50]` | 省略起点、终点 |
| `a[::2]` | `[10, 30, 50]` | 每隔 2 个下标取一个 |
| `a[::-1]` | `[50, 40, 30, 20, 10]` | 反向切片；不修改原序列 |
| `a[:]` | `[10, 20, 30, 40, 50]` | 对列表是浅拷贝；不可变序列不保证创建新对象 |
| `a[99:]` | `[]` | 切片边界越界会截到有效范围，不报下标越界 |
| `30 in a`、`30 not in a` | `True`、`False` | 判断元素是否存在 |
| `[1, 2] + [3]` | `[1, 2, 3]` | 拼接；`range` 不支持 `+` |
| `[0] * 3` | `[0, 0, 0]` | 重复；`range` 不支持 `*` |

切片步长不能为 0。字符串按字符访问：`"abc"[1]` 得到 `'b'`；字典、集合不支持这种序列切片。

## 6. list：列表

初始值：`a = [3, 1, 2, 1]`。下表每行均从这个值开始。

| 写法 | 作用 / 结果 | 返回值 / 注意 |
|---|---|---|
| `a.append(9)` | a 变为 `[3, 1, 2, 1, 9]` | 返回 `None`；一次添加一个元素 |
| `a.append([8, 9])` | a 变为 `[3, 1, 2, 1, [8, 9]]` | 整个列表作为一个元素加入 |
| `a.extend([8, 9])` | a 变为 `[3, 1, 2, 1, 8, 9]` | 返回 `None`；逐个加入可迭代对象中的元素 |
| `a.insert(1, 9)` | a 变为 `[3, 9, 1, 2, 1]` | 返回 `None`；插在指定下标之前，越界时贴到首尾 |
| `a[1] = 9` | a 变为 `[3, 9, 2, 1]` | 按下标修改 |
| `a[1:3] = [8, 9, 10]` | a 变为 `[3, 8, 9, 10, 1]` | 连续切片赋值可以改变长度 |
| `a.pop()` | a 变为 `[3, 1, 2]` | 返回删掉的末尾值 `1` |
| `a.pop(1)` | a 变为 `[3, 2, 1]` | 返回删掉的下标 1 的值 `1`；越界报 `IndexError` |
| `a.remove(1)` | a 变为 `[3, 2, 1]` | 返回 `None`；只删第一个匹配值，找不到报 `ValueError` |
| `del a[1:3]` | a 变为 `[3, 1]` | 删除一个区间；也可用 `del a[i]` 删除单项 |
| `a.clear()` | a 变为 `[]` | 返回 `None` |
| `a.index(1)` | `1` | 第一个匹配值的下标；找不到报 `ValueError` |
| `a.count(1)` | `2` | 出现次数；没有则返回 0 |
| `a.sort()` | a 变为 `[1, 1, 2, 3]` | 返回 `None`；原地排序 |
| `a.sort(reverse=True)` | a 变为 `[3, 2, 1, 1]` | 降序；`reverse=False` 是升序 |
| `a.reverse()` | a 变为 `[1, 2, 1, 3]` | 返回 `None`；反转当前顺序，不排序 |
| `a.copy()` | 得到独立的外层列表 | 浅拷贝；嵌套元素仍共享 |

不要写 `a = a.append(9)`、`a = a.sort()`，否则 a 会变成 `None`。

### 排序规则与建表

| 写法 | 作用 |
|---|---|
| `sorted([3, 1, 2])` | 返回新列表 `[1, 2, 3]`，原列表不变 |
| `sorted(["bbb", "a", "cc"], key=len)` | 按长度升序，得到 `['a', 'cc', 'bbb']` |
| `sorted(rows, key=lambda x: (x[1], -x[2]))` | 第 2 列升序，再按数值型第 3 列降序；`lambda x: ...` 是临时函数，返回比较依据 |
| `[x * x for x in range(4)]` | 列表推导式，得到 `[0, 1, 4, 9]` |
| `[x for x in range(5) if x % 2 == 0]` | 只保留偶数，得到 `[0, 2, 4]` |
| `[[0] * 3 for _ in range(2)]` | 创建 2 行 3 列的独立列表；`_` 表示此处不使用循环变量 |

排序是稳定的：比较依据相同时，保留原先的相对顺序。`sorted(d)` 默认排序字典的键；按字典值排序可用 `sorted(d.items(), key=lambda x: x[1])`。

`b = a` 不复制列表，两者指向同一个对象。不要用 `[[0] * 3] * 2` 建矩阵：两行指向同一个列表，改一行会影响另一行。

## 7. tuple：元组

| 写法 | 作用 / 结果 | 注意 |
|---|---|---|
| `()`、`(1, 2)`、`(1,)` | 空元组、多元素元组、单元素元组 | 单元素必须有逗号；`(1)` 是整数 |
| `a, b = (10, 20)` | a 为 10，b 为 20 | 解包；变量个数要匹配 |
| `first, *rest = (1, 2, 3)` | first 为 1，rest 为 `[2, 3]` | 星号收集的结果是列表 |
| `(1, 2, 1).count(1)` | `2` | 统计次数 |
| `(1, 2, 1).index(2)` | `1` | 查下标；找不到报 `ValueError` |
| `(1, 9) < (2, 0)` | `True` | 从左到右逐项比较，首个不同项决定结果 |

`t[0] = 9` 不允许；但元组内部若装着列表，列表本身仍可修改。元组只有在所有元素都可哈希时，才能作为字典键或集合元素：`(1, "a")` 可以，`(1, [])` 不行。

## 8. dict：字典

初始值：`d = {"A": 2, "B": 1}`。

| 写法 | 作用 / 结果 | 返回值 / 注意 |
|---|---|---|
| `{}`、`dict()` | 创建空字典 | `{}` 不是空集合 |
| `d["C"] = 3` | 新增 C；已有键则覆盖值 | 字典没有 `append()` |
| `d["A"]` | `2` | 键不存在报 `KeyError` |
| `d.get("C")` | `None` | 只查询，不新增键 |
| `d.get("C", 0)` | `0` | 默认值只在键不存在时使用；已有值为 `None` 时仍返回 `None` |
| `"A" in d.keys()` | `True` | 查键；等价于 `"A" in d` |
| `2 in d.values()` | `True` | 查值，需逐个比较 |
| `list(d.keys())` | `['A', 'B']` | 所有键；`keys()` 本身返回视图 |
| `list(d.values())` | `[2, 1]` | 所有值 |
| `list(d.items())` | `[('A', 2), ('B', 1)]` | 所有 `(键, 值)` 对 |
| `d.pop("A")` | 删除 A，字典只剩 B | 返回被删的值 `2` |
| `d.pop("C", 0)` | 字典不变 | 返回默认值 `0`；不传默认值则报 `KeyError` |
| `d.popitem()` | 删除最后插入的键值对 | 返回 `('B', 1)`；空字典报 `KeyError` |
| `del d["A"]` | 删除键 A 及其值 | 键不存在报 `KeyError` |
| `d.setdefault("C", 0)` | 新增 `"C": 0` | 返回 `0`；键已存在时不覆盖，返回原值 |
| `d.update({"A": 9, "C": 3})` | d 变为 `{'A': 9, 'B': 1, 'C': 3}` | 原地合并，冲突时以传入值为准；返回 `None` |
| `d.copy()` | 浅拷贝字典 | 内部的列表、集合等仍共享 |
| `d.clear()` | 清空字典 | 返回 `None` |
| `dict.fromkeys(["A", "B"], 0)` | `{'A': 0, 'B': 0}` | 批量设置相同初始值；不要传 `[]` 等可变默认值，否则会共享 |
| `dict(zip(["A", "B"], [1, 2]))` | `{'A': 1, 'B': 2}` | 两组数据配成键值对 |
| `{k: len(k) for k in ["a", "bb"]}` | `{'a': 1, 'bb': 2}` | 字典推导式 |
| `d \| {"A": 9}` | `{'A': 9, 'B': 1}` | 返回新字典，右边覆盖左边；Python 3.9+ |
| `max(d.keys(), key=d.get)` | `'A'` | 找值最大的键；并列时返回先遇到的键，空字典报 `ValueError` |

字典的键必须可哈希：常用数字、字符串、符合条件的元组；不能用列表、字典、普通集合。

遍历写法：`for k in d.keys():`、`for v in d.values():`、`for k, v in d.items():`。视图会随字典变化；遍历中不要增删键，要删时可遍历 `list(d.keys())` 这个快照。

### 计数与分组

```python
# 计数：不存在就从 0 开始
counts = {}
for x in ["A", "B", "A"]:
    counts[x] = counts.get(x, 0) + 1
# counts == {"A": 2, "B": 1}

# 分组去重：天号 -> 这一天出现过的 IP 集合
logs = [(1, "ipA"), (1, "ipA"), (2, "ipB")]
day_ips = {}
for day, ip in logs:
    day_ips.setdefault(day, set()).add(ip)
# day_ips == {1: {"ipA"}, 2: {"ipB"}}
```

### get() 默认集合与 setdefault()

`get(k, set())` 不会为缺失键保存集合；键已存在时，返回的是字典中原来的集合，修改它会影响字典。

```python
day_ips = {}
day_ips.get(1, set()).add("ipA")
assert day_ips == {}  # 键不存在：改的是临时集合，结果没有保存

day_ips.setdefault(1, set()).add("ipA")
assert day_ips == {1: {"ipA"}}  # 键不存在：先存入集合，再添加元素

day_ips.get(1, set()).add("ipB")
assert day_ips == {1: {"ipA", "ipB"}}  # 键已存在：修改原集合
```

## 9. set：集合

初始值：`s = {1, 2}`。集合元素必须可哈希；无下标，也不保证遍历顺序。

| 写法 | 作用 / 结果 | 返回值 / 注意 |
|---|---|---|
| `set()` | 空集合 | 不能写 `{}` |
| `set("abac")` | `{'a', 'b', 'c'}` | 去重；集合显示顺序不保证 |
| `s.add(3)` | s 变为 `{1, 2, 3}` | 返回 `None`；已有元素不会重复添加 |
| `s.update([2, 3, 4])` | s 变为 `{1, 2, 3, 4}` | 返回 `None`；逐个加入元素 |
| `s.remove(1)` | s 变为 `{2}` | 返回 `None`；元素不存在报 `KeyError` |
| `s.discard(9)` | s 不变 | 返回 `None`；元素不存在也不报错 |
| `s.pop()` | 删除并返回任意一个元素 | 不是随机抽样，也不保证取最小值；不接收参数，空集合报 `KeyError` |
| `1 in s` | `True` | 查询元素 |
| `s.copy()` | 浅拷贝集合 | 返回新集合 |
| `s.clear()` | s 变为空集合 | 返回 `None` |
| `{x % 3 for x in [1, 2, 3, 4]}` | `{0, 1, 2}` | 集合推导式，自动去重 |

### 集合运算

初始值：`a = {1, 2, 3}`，`b = {3, 4}`。下表均不修改 a、b。

| 运算符 / 方法 | 结果 | 含义 |
|---|---|---|
| `a & b` / `a.intersection(b)` | `{3}` | 交集：两边都有 |
| `a \| b` / `a.union(b)` | `{1, 2, 3, 4}` | 并集：至少一边有 |
| `a - b` / `a.difference(b)` | `{1, 2}` | 差集：a 有而 b 没有 |
| `a ^ b` / `a.symmetric_difference(b)` | `{1, 2, 4}` | 对称差：只在一边出现 |
| `a <= b` / `a.issubset(b)` | `False` | a 是否是 b 的子集；允许相等 |
| `a < b` | `False` | a 是否是 b 的真子集；不允许相等 |
| `a >= b` / `a.issuperset(b)` | `False` | a 是否包含 b |
| `a.isdisjoint(b)` | `False` | 是否没有公共元素 |

原地修改用 `a.intersection_update(b)`、`a.difference_update(b)`、`a.symmetric_difference_update(b)`，均返回 `None`；也可用 `&=`、`-=`、`^=`。`a |= b` 原地并入 b。

集合方法通常可接收列表等可迭代对象，例如 `a.intersection([2, 3])`；运算符 `a & b` 要求两边都是集合类对象。不要在遍历集合时增删元素。

## 10. range 与遍历工具

可迭代对象是能被 `for` 逐项读取的对象，如列表、字符串、字典。迭代器记录读取进度，通常只能消费一遍；需要保存所有结果时可用 `list(...)`。

### range

| 写法 | 转成列表后的结果 | 注意 |
|---|---|---|
| `list(range(4))` | `[0, 1, 2, 3]` | 默认从 0 开始，不含终点 |
| `list(range(2, 5))` | `[2, 3, 4]` | 指定起点和终点 |
| `list(range(1, 7, 2))` | `[1, 3, 5]` | 指定正步长 |
| `list(range(4, -1, -1))` | `[4, 3, 2, 1, 0]` | 负步长倒序；不是 `range(4, 0, -1)` |
| `list(range(5, 2))` | `[]` | 方向不匹配，得到空序列 |

`range` 只接受整数参数，步长不能为 0。常用倒序下标：`range(len(a) - 1, -1, -1)`。

### 遍历、映射与过滤

| 写法 | 结果 / 用途 | 注意 |
|---|---|---|
| `list(enumerate(["A", "B"]))` | `[(0, 'A'), (1, 'B')]` | 同时取下标和值；`start=1` 可从 1 编号 |
| `list(zip([1, 2], ["A", "B"]))` | `[(1, 'A'), (2, 'B')]` | 配对；默认以最短输入为准，多余项丢弃 |
| `list(zip(*[[1, 2], [3, 4]]))` | `[(1, 3), (2, 4)]` | 矩阵转置；`*` 将各行展开为多个参数，不齐的行会被截短 |
| `list(map(int, ["1", "2"]))` | `[1, 2]` | 对每项应用函数；`map()` 返回迭代器 |
| `list(filter(lambda x: x > 0, [-1, 0, 2]))` | `[2]` | 保留使条件为真的元素；也可写列表推导式 |
| `list(reversed([1, 2, 3]))` | `[3, 2, 1]` | `reversed()` 返回反向迭代器，不修改原对象 |
| `iter([10, 20])` | 创建迭代器 | 配合 `it = iter([10, 20])` 使用 |
| `next(it)` | 取下一项，并推进位置 | 耗尽时报 `StopIteration` |
| `next(it, None)` | 取下一项，耗尽时返回 `None` | 可换成其他默认值 |

常见循环：`for i, v in enumerate(a):`、`for x, y in zip(a, b):`。

### 生成器表达式与 sorted()

示例：`cnt = {"牛": 3, "666": 3, "hhh": 1}`，`mx = 3`。

| 写法 | 结果 | 注意 |
|---|---|---|
| `[w for w, c in cnt.items() if c == mx]` | `['牛', '666']` | 列表推导式立即生成列表，保留遍历顺序，不自动排序 |
| `(w for w, c in cnt.items() if c == mx)` | 生成器对象 | 按需逐项生成；消费完后不会自动重头开始 |
| `sorted(w for w, c in cnt.items() if c == mx)` | `['666', '牛']` | 生成器是唯一实参时，可以省略它自己的括号 |
| `sorted((w for w, c in cnt.items() if c == mx), reverse=True)` | `['牛', '666']` | 还有其他实参时，生成器表达式必须加括号 |

`sorted()` 接受可迭代对象，总是返回 `list`，输入是元组、集合、生成器也一样；读取生成器时会消耗它。列表推导式本身已有 `[]`，所以 `sorted([w for w, c in cnt.items() if c == mx], reverse=True)` 也合法。

不加括号直接写 `sorted(w for w, c in cnt.items() if c == mx, reverse=True)`，会在解析阶段报 `SyntaxError`，不是运行时的参数类型错误。

### 长度、统计与最值

| 写法 | 结果 | 注意 |
|---|---|---|
| `len([10, 20])` | `2` | 元素个数；字典是键数，集合是去重后的元素数；普通迭代器没有长度 |
| `sum([1, 2, 3])` | `6` | 数值求和；`sum([])` 为 0，不能用来拼字符串 |
| `sum([1, 2], 10)` | `13` | 第二个参数是起始值 |
| `max([1, 3, 2])`、`min([1, 3, 2])` | `3`、`1` | 也可写 `max(1, 3, 2)`；无默认值时空输入报 `ValueError` |
| `max([], default=0)` | `0` | `min()` 也支持空输入默认值 |
| `max(["a", "bbb", "cc"], key=len)` | `'bbb'` | 比较 key 的结果，返回原元素；并列时取先遇到的 |
| `any([0, "", 3])` | `True` | 至少一个元素为真；`any([])` 为 `False` |
| `all([1, "a", True])` | `True` | 全部元素为真；`all([])` 为 `True` |

`sum()`、`max()`、`min()`、`sorted()` 可读取可迭代对象，但要求元素满足相应的加法、比较规则。`reversed()` 要求支持反向遍历，并非所有可迭代对象都能使用。

## 11. collections：队列、计数与默认字典

### deque：双端队列

```python
from collections import deque
q = deque([1, 2, 3])
```

以下每行从 `deque([1, 2, 3])` 开始。观察全部元素可用 `list(q)`。

| 写法 | 操作后的内容 | 返回值 / 注意 |
|---|---|---|
| `q.append(4)` | `[1, 2, 3, 4]` | 返回 `None`；右端加入 |
| `q.appendleft(0)` | `[0, 1, 2, 3]` | 返回 `None`；左端加入 |
| `q.pop()` | `[1, 2]` | 返回右端的 `3` |
| `q.popleft()` | `[2, 3]` | 返回左端的 `1` |
| `q.extend([4, 5])` | `[1, 2, 3, 4, 5]` | 返回 `None`；右端逐个加入 |
| `q.extendleft([4, 5])` | `[5, 4, 1, 2, 3]` | 返回 `None`；逐个从左端加入，因此顺序反过来 |
| `q.rotate(1)` | `[3, 1, 2]` | 返回 `None`；正数向右转，负数向左转，不是反转 |
| `q[0]`、`q[-1]` | 内容不变 | 返回首项 `1`、末项 `3`；不支持切片 |

两端增删通常是 O(1)；列表头部的 `pop(0)`、`insert(0, x)` 是 O(n)。空队列 `pop()`、`popleft()` 报 `IndexError`。`deque(..., maxlen=n)` 满后再从一端加入，会自动丢弃另一端元素。

### Counter：计数器

```python
from collections import Counter
c = Counter("abaca")
# c == {"a": 3, "b": 1, "c": 1}
```

| 写法 | 作用 / 结果 | 注意 |
|---|---|---|
| `c["a"]`、`c["z"]` | `3`、`0` | 缺失键用下标读取时返回 0，且不插入 |
| `c.most_common(2)` | `[('a', 3), ('b', 1)]` | 按次数降序；次数相同按首次出现顺序 |
| `c.update("ab")` | a、b 的次数各加 1 | 累加计数，不是普通字典的覆盖赋值；返回 `None` |
| `c.subtract("aa")` | a 的次数减 2 | 允许出现 0 和负数；返回 `None` |
| `list(c.elements())` | `['a', 'a', 'a', 'b', 'c']` | 按次数展开；忽略非正计数 |
| `sum(c.values())` | `5` | 计数总和；`len(c)` 是保存的不同键数 |

Counter 是字典子类；键数中可能包含计数为 0 的项。`c.get("z")` 仍是普通字典规则，返回 `None`；只有 `c["z"]` 自动给 0。

### defaultdict：自动创建默认值

```python
from collections import defaultdict
```

| 写法 | 用途 | 缺失键的初始值 |
|---|---|---|
| `d = defaultdict(int)` | 计数：`d[x] += 1` | `0` |
| `d = defaultdict(list)` | 分组：`d[k].append(v)` | 每个键单独创建 `[]` |
| `d = defaultdict(set)` | 分组去重：`d[k].add(v)` | 每个键单独创建 `set()` |

自动创建只由 `d[k]` 触发；`d.get(k)`、`k in d.keys()` 不创建键。传入的是 `list`、`set` 这样的函数，不是 `list()`、`set()` 的结果。

## 12. 算法常见工具模块

### functools.reduce：累积合并

```python
from functools import reduce
```

| 写法 | 结果 | 注意 |
|---|---|---|
| `reduce(lambda a, b: a + b, [1, 2, 3])` | `6` | 先合并 1、2，再用结果合并 3；普通求和直接用 `sum()` |
| `reduce(lambda a, b: a ^ b, [2, 3, 2], 0)` | `3` | 从初始值 0 开始逐项异或；同一个整数出现两次会抵消 |
| `reduce(lambda a, b: a ^ b, [], 0)` | `0` | 有初始值时，空输入直接返回初始值 |

格式：`reduce(函数, 可迭代对象, 初始值)`。函数接收两个参数：累计结果、当前元素。不传初始值时，用第一个元素作为起点；此时空输入会报 `TypeError`。

### heapq：堆，操作普通列表

```python
import heapq
h = [3, 1, 2]
heapq.heapify(h)
```

| 写法 | 作用 / 返回 | 注意 |
|---|---|---|
| `heapq.heapify(h)` | 原地建成最小堆，返回 `None` | O(n)；堆的整个列表不是排好序的 |
| `h[0]` | 查看最小值，不删除 | O(1)；空列表报 `IndexError` |
| `heapq.heappush(h, 4)` | 入堆，返回 `None` | O(log n) |
| `heapq.heappop(h)` | 删除并返回最小值 | O(log n)；空堆报 `IndexError` |
| `heapq.heappushpop(h, 4)` | 先入堆，再删除并返回最小值 | 空堆时返回传入值，堆仍为空 |
| `heapq.heapreplace(h, 4)` | 先删除并返回最小值，再入堆 | 要求非空；与上一行不等价 |
| `heapq.nlargest(2, [3, 1, 2])` | `[3, 2]` | 返回前 2 大，降序 |
| `heapq.nsmallest(2, [3, 1, 2])` | `[1, 2]` | 返回前 2 小，升序 |

整数最大堆的兼容写法：入堆存 `-x`，出堆取反。Python 3.14+ 另有 `heapify_max()`、`heappush_max()`、`heappop_max()` 等最大堆接口。

元组入堆按元素依次比较，例如 `(值, 编号)`；首项相同会比较下一项，下一项必须可比较。

### bisect：有序列表二分查找

```python
import bisect
a = [1, 2, 2, 4]
```

| 写法 | 结果 / 作用 | 注意 |
|---|---|---|
| `bisect.bisect_left(a, 2)` | `1` | 第一个大于等于 2 的位置 |
| `bisect.bisect_right(a, 2)` | `3` | 第一个大于 2 的位置；`bisect.bisect()` 与它相同 |
| `bisect.insort_left(a, 2)` | a 变为 `[1, 2, 2, 2, 4]`，返回 `None` | 在已有的 2 之前插入，插入位置为原下标 1 |
| `bisect.insort_right(a, 2)` | a 变为 `[1, 2, 2, 2, 4]`，返回 `None` | 在已有的 2 之后插入，插入位置为原下标 3 |
| `bisect.insort(a, 3)` | a 变为 `[1, 2, 2, 3, 4]`，返回 `None` | `insort()` 是 `insort_right()` 的别名 |

前提是列表已经升序。查找位置 O(log n)，列表插入仍为 O(n)；返回插入位置，不代表目标一定存在。

### re：正则表达式

```python
import re
```

| 写法 | 结果 / 作用 | 注意 |
|---|---|---|
| `re.split(r"[, .?]+", "a,b. c?")` | `['a', 'b', 'c', '']` | 按逗号、空格、点、问号分割；`+` 表示连续一个或多个 |
| `re.escape(".")` | `'\\.'` | 转义正则特殊字符，按普通字符匹配 |
| `re.findall(r"\d+", "a12b3")` | `['12', '3']` | 找出所有匹配；有捕获组时返回结构会变化 |
| `re.search(r"\d+", "a12")` | 返回匹配对象，`.group()` 得到 `'12'` | 搜索任意位置；找不到返回 `None` |
| `re.match(r"\d+", "12a")` | 返回匹配对象，匹配 `'12'` | 只从字符串开头匹配，不要求覆盖全文 |
| `re.fullmatch(r"\d+", "12a")` | `None` | 必须整个字符串都匹配 |
| `re.sub(r"\d+", "#", "a12b3")` | `'a#b#'` | 替换匹配部分 |

`r"..."` 是原始字符串写法，常用于正则，避免 Python 先处理反斜杠。`\d` 默认也可匹配非 ASCII 十进制数字；只要 `0~9` 时用 `[0-9]`。匹配结果先判断不是 `None`，再调用 `.group()`。

## 14. 常见错误与性能

| 情况 | 错误 / 原因 | 处理方式 |
|---|---|---|
| 列表、字符串下标越界；空栈出栈 | `IndexError` | 检查下标范围、是否非空 |
| 字典键、集合待删元素不存在 | `KeyError` | 按需求使用 `get()`、`pop(k, 默认值)`、`discard()` |
| `index()`、`list.remove()` 找不到目标；字符串转数值失败 | `ValueError` | 查找前判断存在；按输入约定解析 |
| 参数类型错误；把列表当字典键 | `TypeError` | 确认参数类型、键是否可哈希 |
| 除数为 0 | `ZeroDivisionError` | 除法、整除、取余前检查除数 |
| 遍历字典或集合时增删元素 | 可能报 `RuntimeError` 或漏处理 | 遍历快照，或先记录待删项再统一删除 |

| 操作 | 常见时间复杂度 | 选用时机 |
|---|---|---|
| `x in list`、`list.index()`、`list.count()` | O(n) | 按位置保存、允许重复 |
| `k in d.keys()`、`d[k]`、`x in set` | 平均 O(1) | 频繁查询、计数、去重；不保证最坏情况 O(1) |
| 列表尾部 `append()` / `pop()` | 摊还 O(1) / O(1) | 栈 |
| 列表头部 `insert(0, x)` / `pop(0)` | O(n) | 频繁操作队头时换 `deque` |
| `list.sort()` / `sorted()` | O(n log n) 最坏情况 | 需要完整排序 |
| 堆的入堆 / 出堆 | O(log n) | 反复取当前最小值或最大值 |
