@sorted 的返回值永远是 list
```python
cnt = {"牛": 3, "666": 3, "hhh": 1}
mx = 3

# ① 列表推导式（你见过）——方括号，立刻生成一个 list
lst = [w for w, c in cnt.items() if c == mx]      # ['牛', '666']，保留字典遍历顺序

# ② 生成器表达式——把 [] 换成 ()，不立刻生成，边用边产
gen = (w for w, c in cnt.items() if c == mx)

# ③ 生成器表达式是函数唯一实参时，可省略它自己的括号；下面两种写法结果相同
sorted(k for k, v in cnt.items() if v == mx)
sorted([k for k, v in cnt.items() if v == mx])

sorted([w for w, c in cnt.items() if c == mx], reverse=True)    # 列表推导式
sorted((w for w, c in cnt.items() if c == mx), reverse=True)    # 生成器表达式
# 还有其他实参时，生成器表达式必须加括号；省略会报 SyntaxError，不是位置参数错误
```

@reduce
```python
from functools import reduce
def find_single(nums):
    return reduce(lambda a, b: a ^ b, nums)   # 累积异或, 一行
```

@bisect
```python
import bisect
a = [1, 2, 2, 4]
x = 2

bisect.bisect_left(a, x)     # 第一个 ≥ x 的下标：1
bisect.bisect_right(a, x)    # 第一个 > x 的下标：3
bisect.bisect(a, x)          # bisect_right 的别名，结果也是 3

bisect.insort_left(a, x)      # 找 left 位置 + 插入
bisect.insort_right(a, x)     # 找 right 位置 + 插入
bisect.insort(a, x)           # insort_right 的别名
```
